# Se Va Todo

Venta privada de objetos únicos: muebles, perfumes, instrumentos, tecnología, decoración y más.

## Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase (auth + base de datos)

## Desarrollo

Necesitás Node.js.

```sh
npm install
npm run dev
```

Copiá `.env.example` a `.env.local` y completá las variables de Supabase antes de correr el proyecto.

## Producción

Deploy en Vercel. El build usa el preset `vercel` de Nitro (ver `vite.config.ts`).
